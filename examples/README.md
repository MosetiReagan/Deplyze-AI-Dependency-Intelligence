# Examples

- `basic/` — a minimal `.deplyze.yml` for a typical application.
- `github-actions/` — a workflow that runs Deplyze and uploads SARIF to code scanning.
- `mcp/` — an MCP client configuration for Claude Desktop / Cursor / Codex.

Run any of them against this repository or your own project:

```bash
npx deplyze scan --config examples/basic/.deplyze.yml
```
